# 最適化器に関する実装方針

## どのようにしてインスタンス化するか

Layerを引数にとる
Optimizerの__init__では以下の動作を行う。
前提としてレイヤーには、(self, 自信が所有する更新対象パラメータの属性名, 自信が所有する更新対象パラメータの勾配の属性名)のタプルのリストを返すメソッドを新たに実装する。
Optimizerは、引数として渡されたLayerのget_paramsを利用し、そのレイヤーにある更新対象パラメータを保持する。
直接パラメータと勾配のリストを持たずに、一度レイヤーと属性名で別で分けて持つ理由は、NumPyの再代入時に参照が切れ、意図しないバグを引き起こすことを避けるためである。

# レイヤーに関する実装方針


## レイヤーのインスタンス化にあたっての引数について

* そのレイヤーの形を決定するために必要な情報
* パラメータが存在する場合に限り、パラメータの初期化方法


## レイヤーが対応する次元について

* レイヤーには一般化を持たせず、1次元または2次元で扱うものとする。
* 各レイヤーの次元はレイヤーの名称に記すものとする。


## レイヤーのパラメータ初期化について

* READMEに記された通り、Standard random initialization / Xavier initialization / He initializationをそれぞれ実装する。
* レイヤーのパラメータを返却するメソッドとして、抽象クラスParametricLayerの中に定義する。
* それぞれの初期化方法で必要な情報は次の通り
    * Standard: 正規分布あるいは一様分布を決定するパラメータ1つ
    * Xavier: 入出力のノード数n_in, n_out
    * He: 入力のノード数n_in
* n_in, n_outの計算方法はLinearとConv2Dで異なるので、これらの計算メソッドは抽象化。結果のn_in, n_outのみプロパティとして利用


## Linear層の計算方法について

多次元にも対応するために、一時的に内部で2次元に直して計算する。
`reshape`を利用する。
`reshape(-1, D)`により2次元に->`reshape(*x.shape[:-1], -1)`により元の形に。

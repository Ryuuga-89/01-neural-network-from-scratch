## reshapeメソッド

numpyの原則は「行優先」で、最も右のインデックス(最後の次元)から先に動かす。
2次元配列 `shape = [H, W]` を例にすれば
(0, 0) -> (0, 1) -> ... -> (0, W-1) -> (1, 0) -> (1, 1) -> ...

配列は以下のようにして保存される。

```python
arr = np.array([[10, 20, 30], [40, 50, 60]])  # shape: (2, 3)

# メモリ上では [10, 20, 30, 40, 50, 60] という一直線の並び順
print(arr.flatten())  # [10 20 30 40 50 60]
```

reshapeメソッドは、まず引数から新しい入れ物の形を決定し、その新しい入れ物にこのメモリ上の値を順番に代入していく。代入するマスの順番も、前述した「行優先」ルールで決まる。

なので例えば

```python
reshaped = arr.reshape(3, 2)
print(reshaped)
# [[10 20]
#  [30 40]
#  [50 60]]
```

となる。
